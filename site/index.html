It reads what just scrolled past.

wisp reads the last 60 lines of your terminal, along with your history, the files in this folder and your git branches.

Before you type, and while you do.

It suggests the next command on an empty prompt, and completes the line once you pause typing for 60 ms.

Press the right arrow key to accept. Alt+F takes one word.

Long commands, put together for you.

It takes the name from your screen and the flags from what you ran before.

Four commands, then one check.

You need zsh on macOS or Linux, and about 2 to 4.5 GB of memory for the model.

  1. brew install llama.cpp
  2. curl -fsSL https://raw.githubusercontent.com/lolabradora/wisp/main/install.sh | sh
  3. wisp setup
  4. echo 'eval "$(wisp init zsh)"' >> ~/.zshrc
  5. wisp doctor
